    Software Tools

    A summary of tools from open-source repositories, for loading, converting, storing, and analyzing electrochemical measurement data. The list is non-exhaustive and the maintenance status of community projects may change. To add a project to this list, see suggest a link.

    A curated list of tools related to chemistry can be found elsewhere.

    Loaders and converters — interfacial electrochemistry and general

    Name Scope / formats Reference
    eclabfiles BioLogic .mpt/.mpr/.mps; largely folded into yadg
    galvani reads BioLogic .mpr/.mpt and Arbin .res into pandas
    impedance.py EIS; BioLogic, Gamry .DTA, CSV; fitting and plotting DOI
    ixdat in-situ data; BioLogic, Autolab, Ivium, CH Instruments, EC-MS, echemdb
    MADAP common formats; EIS, Arrhenius, voltammetry analysis DOI
    unitpackage header-aware loaders creating unit-aware frictionless datapackages (echemdb project) DOI
    yadg many instrument formats to NetCDF datagrams; EIS supported DOI

    Loaders — battery cyclers

    Name Scope / formats Reference
    BEEP Arbin, BioLogic, Maccor, Neware; featurization DOI
    cellpy Arbin, Maccor, PEC, Neware, BioLogic DOI
    galv (Galvanalyser) Maccor, Ivium, BioLogic; storage platform with metadata arXiv
    PyProBE several cyclers; Polars/Parquet backend DOI
